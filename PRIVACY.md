# Privacy Policy - tomorrowly-bot

tomorrowly-bot is a private tool used only by the owner of the YouTube channel "Tomorrowly" to upload the owner's own videos and read the owner's own channel analytics.

- It accesses only the owner's YouTube account, with the owner's permission (Google OAuth).
- It does not collect, store, sell or share any data about other people.
- YouTube analytics numbers are stored only in this repository to improve future videos.
- Access can be removed at any time at https://myaccount.google.com/permissions

Contact: through the YouTube channel "Tomorrowly".
